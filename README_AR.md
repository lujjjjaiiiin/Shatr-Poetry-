# تقارير فعلية لهذه النسخة

هذه الملفات خرجت من تشغيل نسخة شطر الجديدة في Colab يوم 26 أكتوبر 2026. لا تحتوي أوزان المصنف أو بيانات الشعر الكاملة.

- baseline_validation.json: نتائج TF-IDF وLogistic Regression على validation.
- basma_model/: مقاييس وتقارير AraBERT المدرب لثلاث دورات، وتوقيع بياناته وإعداداته.
- shatr_smoke/validation_metrics.json: خسارة فحص LoRA صغير فقط؛ ليست قياسًا لجودة الشعر ولا نتيجة التدريب الكامل.
- data/: بيانات وصفية عن التقسيم وأعداد الشعراء والأمثلة، لا نصوص القصائد.
- report/: تقرير فعلي ومصفوفة الالتباس؛ المقارنة الإنتاجية والتقييم البشري والاختبار النهائي لم تنفذ بعد.

لا تنقلي training_info.json إلى نموذج آخر لتجاوز فحص التوقيع. استعملي الأوزان والبيانات المطابقتين من نفس التجربة.

أضيفت مقارنة AraPoemBERT الفعلية. `arapoembert_model/` يحتوي مقاييسه وتوقيع بياناته. `classifier_comparison.csv` يقارن النموذجين، و`selected_classifier.json` يسجل اعتماد AraPoemBERT للواجهة وفق Macro-F1. لم تستخدم نتائج test.
