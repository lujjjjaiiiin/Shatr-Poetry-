## ابدئي من هنا

1. افتحي `Shatr_Complete.ipynb` في Colab واختاري T4 GPU.
2. خلية الإعداد تطلب ملف `Shatr_Project.zip` مرة واحدة وتربط Drive. تستخدم مجلد تشغيل مؤقتًا `/content/shatr_project_v1` ومجلد حفظ جديدًا `MyDrive/shatr_project_v1`، ولا تعدل مشروع Basma السابق.
3. شغلي اختبارات الكود. ثم جهزي البيانات مرة واحدة من الأزواج السابقة التي راجعتماها في `MyDrive/basma_project`.
4. شغلي خط الأساس، ثم تدريب AraBERT وAraPoemBERT، ثم اختيار الأعلى Macro-F1 وإصدار التقرير. قارنيهما على نفس التقسيم الجديد.
5. شغلي Qwen قبل التدريب، ثم LoRA، ثم مقارنة قبل/بعد. لا تشغلي الاختبار النهائي الآن.
6. نفذا التقييم البشري الأعمى قبل كشف مفتاح A/B.
7. صدّري المصنف المدرب من خلية التنزيل، ثم افتحي الواجهة. تظل الميزات غير المدربة معطلة بوضوح؛ لا نستخدم نصوصًا أو نسبًا وهمية.

تشغيل الواجهة في جلسة Colab جديدة يحتاج تثبيت المتطلبات وخلية الإعداد واستعادة البيانات وأرشيف المصنف الذي نزلتماه. إضافات LoRA الصغيرة تُحفظ مع النتائج؛ أوزان المصنف وcheckpoints تبقى مؤقتة ويجب تصدير المصنف قبل إنهاء الجلسة. هذا يحافظ على مساحة Drive المحدودة. عند تشغيل GPU في Colab، أغلقي واجهة قديمة قبل فتح المنفذ نفسه. لا تنهي الجلسة قبل حفظ الملفات اللازمة.

## لماذا هذه القرارات؟

- **نقسم الشعراء، ثم نأخذ الأمثلة:** توزيع أبيات الشاعر نفسه على التدريب والتحقق قد يجعل التقييم يقيس تذكر الشاعر بدل تعميم العصر.
- **ثلاثة شعراء على الأقل لكل عصر في التحقق والاختبار:** تحسين أولي للتمثيل، وليس ضمانًا للتنوع. نعرض الأعداد الفعلية بعد إزالة التكرار.
- **التناوب بين الشعراء:** نقلل هيمنة الشاعر كثير القصائد عند تطبيق سقف الأمثلة.
- **Macro-F1 لاختيار المصنف:** يعامل العصور بالتساوي؛ نعرض Accuracy ونتائج كل عصر أيضًا.
- **LoRA:** ندرب إضافات صغيرة على Qwen بدل تحديث أوزانه كلها. ملف adapter يحتاج النموذج الأساسي عند الاستخدام.
- **خسارة التكملة فقط:** `labels=-100` للتعليمات والشطر الأول والحشو؛ نحسب الخطأ على الشطر الثاني وEOS.
- **البحث من التدريب فقط:** TF-IDF وcosine similarity يقيسان تشابهًا لفظيًا، ولا يثبتان التأثر أو الاقتباس.
- **تحميل كل ميزة عند طلبها:** لا ننزل Qwen لمجرد فتح الواجهة، ويمكن فحص التصميم قبل تدريب النماذج.

## التشغيل من الطرفية

يفضل Python 3.10–3.12. هذه الإصدارات واجهات معروفة وليست ملف قفل لجميع المكتبات. في Colab اختبري البيئة أولًا، وإذا ظهرت مشكلة استيراد بعد التثبيت أعيدي جلسة Python ثم الإعداد.

```powershell
python -m pip install -r requirements.txt
$env:SHATR_ROOT = 'C:\path\to\shatr_project_v1'
python test_project.py
python test_features.py
python prepare_project.py --old-root 'C:\path\to\basma_project' --new-root $env:SHATR_ROOT
python train_classifier.py baseline
python train_classifier.py train --model arabert --epochs 3
python train_classifier.py train --model arapoembert --epochs 3
python select_classifier.py
python train_completion.py before
python train_completion.py train --epochs 2
python train_completion.py compare
python make_report.py
python app.py
```

أوامر `--smoke` تفحص مسار التنفيذ بعينة صغيرة؛ لا تنقلي أرقامها إلى تقرير النتائج. فحوص الدخان للمولد والمصنف تحفظ في مجلدات منفصلة.

## التقييم النهائي بعد تثبيت القرارات

```powershell
python train_classifier.py test --model arabert
python train_classifier.py test --model arapoembert
python train_completion.py test
```

لا تستخدمي test لاختيار معدل تعلم أو عصر أو أفضل نموذج. إجراء تجارب كثيرة على validation يحد من استقلاله أيضًا؛ سجلي عدد التجارب ولا تعتبري ارتفاعه ضمانًا للتعميم.

## حالة نتائجنا السابقة

AraPoemBERT السابق حقق 61.20% على تحقق التقسيم القديم. هذه نتيجة تاريخية لتجربة مختلفة، وليست نتيجة AraBERT في نسخة شطر الجديدة. لا ننقل الأوزان القديمة إلى تقسيم جديد لأن بعض الشعراء الذين تدربت عليهم قد يصبحون ضمن الاختبار الجديد.

## حدود الاستخدام

التصنيف ترجيح ضمن الجاهلي والأندلسي والعثماني والحديث، وليس إثباتًا لتاريخ النص أو هوية مؤلفه. الدرجات ليست احتمالات معايرة. التكملة لا تضمن الوزن أو القافية أو الأصالة. قد يعرف النموذج قصائد مشهورة من تدريبه المسبق. تطابق الأسماء والنصوص لا يكشف جميع الأسماء البديلة أو الاقتباسات القريبة.

## استعادة أرشيف المصنف

```powershell
python restore_model.py --archive Shatr_AraBERT_Model.zip --root $env:SHATR_ROOT
```

يفحص البرنامج توقيع البيانات قبل وضع الأوزان، ويرفض المسارات الخارجة عن المجلد أو استبدال أوزان موجودة بصمت.

## AraPoemBERT ضمن النسخة الجديدة

النموذجان يستخدمان عينات التدريب والتحقق نفسها، ولكل واحد مجلد مستقل: `basma_model` لـAraBERT و`arapoembert_model` لـAraPoemBERT. يفحص `select_classifier.py` تطابق بيانات التحقق وترتيبها ثم يحفظ `selected_classifier.json`. تقرأ الواجهة هذا الملف عند تشغيلها؛ أعيدي تشغيل الواجهة بعد تغيير الاختيار. لا نختار بناء على test.

لاستعادة أرشيف AraPoemBERT استخدمي `restore_model.py --model arapoembert` مع بقية المسارات.
